# Asset Credits

This prototype currently uses a project-generated pixel starter asset pack created at runtime with Phaser canvas textures.

The game code is structured so external free/commercial-safe pixel art can replace these generated textures later without changing the scene logic:

- `shop-floor`
- `shop-walls`
- `counter`
- `register`
- `sealer`
- `fridge`
- `menu`
- `plant`
- `table`
- `chair`
- `door`
- `window`
- `hero`

When replacing assets with a downloaded pack, record the pack name, author, license, source URL, and any attribution requirements here before shipping.
